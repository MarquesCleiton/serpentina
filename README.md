# Serpentina

O clássico jogo da cobrinha, em 2D e 3D, feito em Unity e publicado em WebGL.

**Jogar:** https://marquescleiton.github.io/serpentina/

## Controles
**Computador**
- Setas / WASD: mover
- V: alternar entre visão 2D e 3D
- Esc: pausar

**Celular** (na vertical)
- Deslize o dedo na direção em que a cobra deve ir
- Botão 3D/2D no canto inferior esquerdo, pausa no canto inferior direito
